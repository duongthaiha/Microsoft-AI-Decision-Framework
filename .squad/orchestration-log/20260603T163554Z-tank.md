## Discovered Pre-Existing Wave 5 Issue

`processMessage` returns `readinessState` from computed `evaluateReadiness()` rather than from stored `session.conversationCapture.readinessState`. This causes returned state to show `phase1InProgress` even after recommendation delivery.

**Workaround:** Demo scripts detect recommendation via `messageType === 'recommendation'`  
**Proposed fix (Wave 5):** Return stored state directly from `processMessage`
